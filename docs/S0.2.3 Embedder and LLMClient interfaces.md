# S0.2.3 — Embedder and LLMClient interfaces

> **As a Dev, I want Embedder and LLMClient interfaces with Ollama implementations, so that I can swap providers later via config.**

**Acceptance criteria:**
1. Interfaces in **`app/providers/`**
2. The Ollama implementations use the **OpenAI-compatible endpoint** (`/v1`)
3. `LLMClient` supports **streaming**
4. The **embedding dimension is read from config** (`EMBEDDING_DIM`)
5. **Unit tests with a fake provider**

**Size:** M (1–2 days). Depends on S0.2.2, which must be merged first.

**Out of scope, don't build it yet:**
- **Batching and retries.** That's S1.5.2: batches of 32–128, exponential backoff. `embed_documents` takes whatever list it's given.
- **L2 normalisation.** Ollama already returns unit-length vectors (I measured a norm of 1.0).
- **Token usage.** The SSE `done` event's `usage` is S2.2. `stream()` yields text only for now.
- **Wiring the providers into the API lifespan or the ARQ worker context.** Nothing calls them yet. The first consumer, ingestion in F1.5, wires them in.
- **Any provider other than Ollama.** The interfaces and the `*_PROVIDER` settings make room for one. Adding one is a later story.
- **Changing the health check.** It keeps using Ollama's own `/api/tags` to check that the models are pulled.

## Architecture

S0.2.3 puts a thin layer between the code that needs AI (ingestion, chat, the worker) and the service that provides it (Ollama). The rest of the app only ever sees the two interfaces.

```
┌───────────────────────────────────────────────────────────────────────┐
│ Callers, from later stories: ingestion (F1.5), chat (F2.x),           │
│ the worker. They only know Embedder and LLMClient, never Ollama       │
└────────┬───────────────────▲──────────────────────────────────────────┘
         │ create_*(settings)│ returns an Embedder / an LLMClient
         ▼                   │
┌────────────────────────────┴────┐          ┌──────────────────────────┐
│ providers/factory.py            │◀─ reads ─│ config.py: Settings      │
│ match settings.*_provider:      │          │ from .env: *_PROVIDER,   │
│   case "ollama": ...            │          │ models, dim, prefixes    │
└────────┬────────────────────────┘          └──────────────────────────┘
         │ builds
         ▼
┌─────────────────────────────────┐          ┌──────────────────────────┐
│ providers/ollama.py             │── fits ─▶│ providers/base.py        │
│ OllamaEmbedder                  │          │ Embedder  (Protocol)     │
│ OllamaLLMClient                 │          │ LLMClient (Protocol)     │
│                                 │          │ ChatMessage, complete(), │
└────────┬────────────────────────┘          │ ProviderError            │
         │                                   └─────────────┬────────────┘
         │ httpx2 → OLLAMA_BASE_URL/v1                     ▲ fits
         ▼                                                 │
┌─────────────────────────────────┐          ┌─────────────┴────────────┐
│ Ollama on the Windows host      │          │ tests/fakes.py           │
│ POST /v1/embeddings             │          │ FakeEmbedder             │
│ POST /v1/chat/completions (SSE) │          │ FakeLLMClient            │
│                                 │          │ no network: unit tests   │
└─────────────────────────────────┘          └──────────────────────────┘
```

How to read it:
- **`base.py` is the contract.** It says what an embedder and an LLM client can do, and nothing about how.
- **Two things fit the contract:** the real Ollama classes and the test fakes. The arrows marked "fits" are checked by mypy. Nothing inherits from anything.
- **`factory.py` is the only file that names a concrete class.** It reads `Settings` and decides which one to build. Swapping providers means a new class plus one `case`, and nothing upstream changes.
- **Only `ollama.py` touches the network.** It is the one file that knows about httpx2, `/v1` URLs, SSE, Ollama's error format and `reasoning_effort`.

**What happens when a caller streams an answer:**

```
caller                 OllamaLLMClient.stream()               Ollama
  │ async for delta in ──▶ build the JSON payload
  │                        POST /v1/chat/completions ──────────▶
  │                                    ◀── 200, text/event-stream
  │                        data: {"delta":{"reasoning":"Hmm"}}   skipped
  │ ◀── "Hello" ────────── data: {"delta":{"content":"Hello"}}
  │ ◀── " there" ───────── data: {"delta":{"content":" there"}}
  │                        data: {"choices":[],"usage":{...}}    skipped
  │ loop ends ◀─────────── data: [DONE]                          return
```

Each `yield` reaches the caller as soon as Ollama sends that chunk. That is what will let S2.2 forward tokens to the browser while the answer is still being written.

## Step 1 — Config: what the providers need

Before writing any code, I sent real requests to the `/v1` endpoints. They returned three things that shape the settings:

1. **`qwen3` thinks before it answers, and the thinking counts against `max_tokens`.** With `max_tokens: 200`, all 200 tokens went to `delta.reasoning`, and the answer `content` was empty. At about 6 tokens/s on this CPU, that was 32 seconds for nothing. With `"reasoning_effort": "none"`, the reply came back in 7 tokens, with no reasoning at all.
2. **`nomic-embed-text` needs task prefixes.** It was trained with `search_document: ` before passages and `search_query: ` before questions. Without them, retrieval quality drops. Other models use other prefixes, or none.
3. **A long prompt is slow before the first token arrives.** The prompt was processed at roughly 20–45 tokens/s here, so the ~6k tokens of sources (D10) can take minutes.

**`docqa-backend/app/config.py`**: replace the Ollama block (`ollama_base_url` … `embedding_dim`) with:

```python
    # Which implementation create_llm_client() and create_embedder() build
    llm_provider: Literal["ollama"] = "ollama"
    embedding_provider: Literal["ollama"] = "ollama"

    ollama_base_url: str = "http://localhost:11434"
    llm_model: str = "qwen3:8b"
    # "none" turns qwen3's thinking off; thinking tokens are slow on a CPU and never shown
    llm_reasoning_effort: Literal["none", "low", "medium", "high"] = "none"
    # Seconds to wait for the next streamed token; a 6k-token prompt on a CPU takes minutes
    llm_timeout_seconds: float = 300.0

    embedding_model: str = "nomic-embed-text"
    embedding_dim: int = 768
    # nomic-embed-text expects these task prefixes; set both to "" for models without them
    embedding_document_prefix: str = "search_document: "
    embedding_query_prefix: str = "search_query: "
```

- **`llm_provider` / `embedding_provider`**: this is the "swap via config" part. Each is a `Literal` with one value today, so a typo like `LLM_PROVIDER=olama` fails at startup instead of at the first question. A new provider adds a value here and a `case` in Step 4. The two are separate, so the answers could later come from a hosted model while the embeddings stay local.
- **`llm_reasoning_effort`**: this is a decision; record it in your decision log. `"none"` keeps answers fast and keeps the token budget for the answer. Thinking can be tried again in Phase 3, when the evaluation set can measure whether it helps.
- **`llm_timeout_seconds`**: for a streamed response, httpx2's timeout limits the wait *between* chunks, not the whole answer. 300 s covers the long silence before the first token.
- **`embedding_dim`** is unchanged. Step 3 now enforces it.

**`.env.example`**: replace the Ollama section with:

```bash
# ---------- Ollama (runs on the Windows host, decision D10) ----------

# Which implementation the backend builds; only "ollama" exists so far

EMBEDDING_PROVIDER=ollama

# none | low | medium | high. "none" turns qwen3's thinking off (faster, nothing hidden)

# Must match the embedding model; fixes the VECTOR(n) column (D5)

# Task prefixes nomic-embed-text was trained with. Keep the quotes: they keep the trailing space.
# Set both to "" for a model that doesn't use prefixes.
```

Copy the same lines into your own `.env`. **Keep the quotes.** Compose turns `EMBEDDING_QUERY_PREFIX=search_query: ` (unquoted) into `search_query:`, with no space.

## Step 2 — `app/providers/base.py`: the interfaces

Create `app/providers/__init__.py` (empty), then:

```python
from collections.abc import AsyncIterator, Sequence
from dataclasses import dataclass
from typing import Literal, Protocol


@dataclass(frozen=True, slots=True)
class ChatMessage:
    role: Literal["system", "user", "assistant"]
    content: str


class ProviderError(Exception):
    """A provider call failed: unreachable, an error reply, or a reply we can't use."""


class Embedder(Protocol):
    """Turns text into vectors. Documents and queries are embedded differently by some models."""

    @property
    def dim(self) -> int: ...

    async def embed_documents(self, texts: Sequence[str]) -> list[list[float]]: ...

    async def embed_query(self, text: str) -> list[float]: ...

    async def aclose(self) -> None: ...


class LLMClient(Protocol):
    """Chat completion, streamed as text deltas."""

    def stream(
        self,
        messages: Sequence[ChatMessage],
        *,
        temperature: float = 0.2,
        max_tokens: int | None = None,
    ) -> AsyncIterator[str]: ...

    async def aclose(self) -> None: ...


async def complete(
    llm: LLMClient,
    messages: Sequence[ChatMessage],
    *,
    temperature: float = 0.2,
    max_tokens: int | None = None,
) -> str:
    """The whole answer at once, for short calls like query rewriting."""
    deltas = llm.stream(messages, temperature=temperature, max_tokens=max_tokens)
    return "".join([delta async for delta in deltas])
```

- **`Protocol`, not an abstract base class.** A class matches if it has the right methods. The fakes in Step 5 don't inherit anything, and mypy still checks that they fit (Step 6, first test). The architecture rule "services free of FastAPI imports" holds here too: nothing in `providers/` imports FastAPI.
- **`embed_documents` vs `embed_query`.** Models like nomic embed the two sides differently. Callers say which side the text is on, and the implementation adds the right prefix. Ingestion code never needs to know about `search_document: `.
- **`dim`** is exposed so that later code can check it against the `VECTOR(n)` column without reading `Settings` itself.
- **`stream()` is a plain `def` returning `AsyncIterator[str]`.** That's how a Protocol describes an `async def` that contains `yield`. Calling it returns the iterator straight away, and the request starts on the first `async for`.
- **`complete()` is a function, not a method.** Every provider gets it for free, and a fake only has to implement `stream()`. Query rewriting and conversation titles (Phase 3) will use it.
- **`aclose()`**: each implementation owns an HTTP connection pool. Whoever creates the provider closes it, the same way `engine.dispose()` runs on shutdown.
- **One error type, `ProviderError`.** Callers catch it without knowing whether httpx2, a 404 or a bad JSON line was the cause.

### How the code works

**`ChatMessage`**: one message in a conversation.
- `@dataclass` writes `__init__`, `__repr__` and `__eq__` for you, so `ChatMessage(role="user", content="Hi?")` just works.
- `frozen=True` makes a message read-only after it's created. A message can then be put into the history and into a prompt without either one changing it for the other.
- `slots=True` gives each object a fixed set of fields. It uses less memory, and a typo like `msg.contnet = ...` raises an error instead of quietly adding a new attribute.
- `role: Literal["system", "user", "assistant"]` limits the roles to the three that every OpenAI-compatible API understands. mypy rejects `role="bot"`.

**`ProviderError`**: an ordinary exception with a docstring as its only body. Its type says "the AI provider failed", and its message says how.

**`Embedder(Protocol)`**: a list of method signatures. The bodies are `...` because a Protocol never runs; it only describes a shape.

| Member | Takes | Returns | Meaning |
|---|---|---|---|
| `dim` (property) | | `int` | Length of every vector this embedder produces |
| `embed_documents` | `Sequence[str]` (a list or tuple of chunks) | `list[list[float]]` | One vector per text, in the same order |
| `embed_query` | one `str` | `list[float]` | One vector for a question |
| `aclose` | | `None` | Closes the HTTP connections |

**`LLMClient(Protocol)`**: one way to generate, `stream()`, plus `aclose()`.
- The bare `*` after `messages` makes `temperature` and `max_tokens` keyword-only. Calls read as `stream(msgs, temperature=0)`, and parameters can be added later without breaking any caller.
- `temperature=0.2` is low on purpose. A grounded answer should stick to the sources, not be creative.
- `max_tokens=None` means no limit from our side; the model stops when it's done.

**`complete()`**: `stream()` with the results collected.
- `[delta async for delta in deltas]` is an async list comprehension. It runs the stream to the end and keeps every piece.
- `"".join(...)` glues the pieces into one string.
- It takes any `LLMClient`, so it works with the Ollama client, the fake, and any future provider.

How later code will use these types:

```python
messages = [
    ChatMessage(role="system", content="Answer only from the sources."),
    ChatMessage(role="user", content="What is the notice period?"),
]

async for delta in llm.stream(messages):  # piece by piece, for the chat UI
    print(delta, end="")

title = await complete(llm, messages, max_tokens=20)  # all at once, for short internal calls
```

## Step 3 — `app/providers/ollama.py`: the Ollama implementations

```python
import json
from collections.abc import AsyncIterator, Sequence
from typing import Any, Literal

import httpx2

from app.providers.base import ChatMessage, ProviderError

ReasoningEffort = Literal["none", "low", "medium", "high"]


def _client(
    base_url: str, timeout: float, transport: httpx2.AsyncBaseTransport | None
) -> httpx2.AsyncClient:
    # Ollama's OpenAI-compatible API lives under /v1
    return httpx2.AsyncClient(
        base_url=f"{base_url.rstrip('/')}/v1", timeout=timeout, transport=transport
    )


def _error_message(response: httpx2.Response) -> str:
    # OpenAI-style errors look like {"error": {"message": "..."}}
    try:
        return f"{response.status_code}: {response.json()['error']['message']}"
    except (ValueError, KeyError, TypeError):
        return f"{response.status_code}: {response.text[:200]}"


class OllamaEmbedder:
    def __init__(
        self,
        *,
        base_url: str,
        model: str,
        dim: int,
        document_prefix: str = "",
        query_prefix: str = "",
        timeout: float = 60.0,
        transport: httpx2.AsyncBaseTransport | None = None,
    ) -> None:
        self._model = model
        self._dim = dim
        self._document_prefix = document_prefix
        self._query_prefix = query_prefix
        self._http = _client(base_url, timeout, transport)

    @property
    def dim(self) -> int:
        return self._dim

    async def embed_documents(self, texts: Sequence[str]) -> list[list[float]]:
        return await self._embed([self._document_prefix + text for text in texts])

    async def embed_query(self, text: str) -> list[float]:
        [vector] = await self._embed([self._query_prefix + text])
        return vector

    async def aclose(self) -> None:
        await self._http.aclose()

    async def _embed(self, inputs: list[str]) -> list[list[float]]:
        if not inputs:
            return []

        try:
            response = await self._http.post(
                "/embeddings", json={"model": self._model, "input": inputs}
            )
        except httpx2.HTTPError as exc:
            raise ProviderError(f"embedding request failed: {exc!r}") from exc
        if response.is_error:
            raise ProviderError(f"embedding request failed: {_error_message(response)}")

        try:
            rows = sorted(response.json()["data"], key=lambda row: row["index"])
            vectors: list[list[float]] = [row["embedding"] for row in rows]
        except (ValueError, KeyError, TypeError) as exc:
            raise ProviderError(f"unexpected embedding response: {exc!r}") from exc

        if len(vectors) != len(inputs):
            raise ProviderError(f"sent {len(inputs)} texts, got {len(vectors)} vectors")
        # A wrong size would only fail later, when the vector is written to VECTOR(n)
        for vector in vectors:
            if len(vector) != self._dim:
                raise ProviderError(
                    f"{self._model} returned {len(vector)} dimensions, "
                    f"but EMBEDDING_DIM is {self._dim}"
                )
        return vectors


class OllamaLLMClient:
    def __init__(
        self,
        *,
        base_url: str,
        model: str,
        reasoning_effort: ReasoningEffort = "none",
        timeout: float = 300.0,
        transport: httpx2.AsyncBaseTransport | None = None,
    ) -> None:
        self._model = model
        self._reasoning_effort = reasoning_effort
        self._http = _client(base_url, timeout, transport)

    async def stream(
        self,
        messages: Sequence[ChatMessage],
        *,
        temperature: float = 0.2,
        max_tokens: int | None = None,
    ) -> AsyncIterator[str]:
        payload: dict[str, Any] = {
            "model": self._model,
            "messages": [{"role": m.role, "content": m.content} for m in messages],
            "stream": True,
            "temperature": temperature,
            "reasoning_effort": self._reasoning_effort,
        }
        if max_tokens is not None:
            payload["max_tokens"] = max_tokens

        try:
            async with self._http.stream("POST", "/chat/completions", json=payload) as response:
                if response.is_error:
                    await response.aread()
                    raise ProviderError(f"chat request failed: {_error_message(response)}")

                async for event in httpx2.EventSource(response):
                    if event.data == "[DONE]":
                        return
                    for delta in _content_deltas(event.data):
                        yield delta
        except httpx2.HTTPError as exc:
            raise ProviderError(f"chat request failed: {exc!r}") from exc

    async def aclose(self) -> None:
        await self._http.aclose()


def _content_deltas(data: str) -> list[str]:
    try:
        chunk = json.loads(data)
    except ValueError as exc:
        raise ProviderError(f"unexpected chat chunk: {data[:200]}") from exc
    if "error" in chunk:
        raise ProviderError(f"chat stream failed: {chunk['error']}")

    # Thinking arrives in delta.reasoning and is skipped; the last chunk only carries usage
    return [
        choice["delta"]["content"]
        for choice in chunk.get("choices", [])
        if choice.get("delta", {}).get("content")
    ]
```

**Embedder:**
- **`/v1/embeddings`** with `input` as a list sends the whole batch in one request. The reply's `data` rows each carry an `index`. They're sorted by it, because the OpenAI format doesn't promise the order.
- **The dimension check** turns a model or config mismatch into a clear error now. Without it, the mismatch would surface later as a pgvector error when a chunk is inserted, far from the cause. This is the "dimension read from config" criterion.
- **`[vector] = ...`** in `embed_query` also checks that exactly one vector came back.

**LLM client:**
- **`/v1/chat/completions` with `"stream": true`** answers with server-sent events, `data: {...}` lines ending with `data: [DONE]`. I checked the header: Ollama sends `Content-Type: text/event-stream`, which `httpx2.EventSource` requires.
- **Only `delta.content` is yielded.** `delta.reasoning` (thinking, if it's turned on), the empty first `content`, and the final chunk with `usage` and an empty `choices` are all skipped.
- **Errors arrive in two places.** If the request itself fails, for example with an unknown model, Ollama answers with a status code and an OpenAI-style body: `404 {"error":{"message":"model 'nope:1b' not found"}}`. The body has to be read with `aread()` before `.json()` works on a streamed response. An error can also appear in the middle of the stream, as a `data: {"error": ...}` line.
- **`httpx2.HTTPError`** covers connection refused, timeouts, and `SSEError` (the wrong content type). It's wrapped once, at the outer `try`.
- **Stopping early** is already handled. If a caller stops iterating and the generator is closed, the `async with` exits, the connection closes, and Ollama stops generating. S2.2's "stop generating" builds on this.
- **`transport=`** exists for the tests. Production code leaves it as `None`, and httpx2 uses the real network.

The OpenAI-compatible endpoint is what makes a provider swap cheap. vLLM, LM Studio, OpenAI, Groq and others accept the same requests, so a later implementation may only differ in `base_url`, an API key header and which extra fields it sends (`reasoning_effort`).

### How the code works

**Module-level helpers**

- **`ReasoningEffort`**: a name for the four allowed values, so the type isn't written out again in the constructor.
- **`_client()`**: builds the `httpx2.AsyncClient` each provider keeps for its whole life.
  - **One client per provider, not one per request.** The client keeps TCP connections open (a connection pool) and reuses them, which saves a handshake on every call.
  - **`base_url=".../v1"`** lets the methods use short paths like `"/embeddings"`.
  - **`rstrip('/')`** stops `OLLAMA_BASE_URL=http://host:11434/` from turning into `http://host:11434//v1`.
  - **`transport`** is `None` in production, which means the real network. The tests pass a `MockTransport`.
- **`_error_message()`**: turns an error response into one readable line.
  - It first tries the OpenAI error shape, `{"error": {"message": ...}}`.
  - `ValueError` covers a body that isn't JSON (`JSONDecodeError` is a `ValueError`). `KeyError` and `TypeError` cover JSON of a different shape.
  - Whatever happens, it falls back to the status code and the first 200 characters of the body.

**`OllamaEmbedder`**

- **`__init__(self, *, ...)`**: the `*` makes every argument keyword-only. Six arguments, several of them strings, are easy to swap by accident when passed by position. The constructor only stores values and creates the client; it makes no network call.
- **`dim`**: a read-only property over `self._dim`. Callers can read it, but can't change it.
- **`embed_documents()`**: puts `document_prefix` in front of every text and hands the list to `_embed()`.
- **`embed_query()`**: puts `query_prefix` in front, wraps the single text in a list, and unpacks the single vector that comes back (`[vector] = ...`).
- **`_embed()`** does the work in four stages. Each stage turns its own kind of failure into a `ProviderError`:

  | Stage | Code | Fails when | Becomes |
  |---|---|---|---|
  | 1. Nothing to do | `if not inputs: return []` | | No request is sent at all |
  | 2. Send | `await self._http.post(...)` | Ollama is down, or the request times out | `ProviderError("... ConnectError(...)")` |
  | 3. Status | `if response.is_error` | 4xx/5xx, such as an unknown model | `ProviderError("... 404: model 'x' not found")` |
  | 4. Read and check | sort by `index`, count, size | Unexpected JSON, a missing vector, the wrong size | `ProviderError` saying which |

  `raise ProviderError(...) from exc` keeps the original exception attached as `__cause__`, so the full traceback still shows the httpx2 error underneath.

**`OllamaLLMClient.stream()`**, line by line

1. **Build `payload`.** It is typed `dict[str, Any]` because the values mix strings, a bool, a float and a list. `max_tokens` is added only when the caller set it, so Ollama's own default applies otherwise.
2. **`async with self._http.stream("POST", ...) as response:`** sends the request but doesn't download the body. Inside the block, the status and headers are known while the body is still arriving.
3. **`if response.is_error:`** handles a failed request. A streamed body isn't loaded yet, so `await response.aread()` reads it before `_error_message()` can parse it.
4. **`async for event in httpx2.EventSource(response):`** turns the raw bytes into events. Each blank-line-separated `data: ...` block becomes one `event`, and `event.data` is the text after `data: `.
5. **`if event.data == "[DONE]": return`** ends the stream. In an async generator, `return` stops it, and the caller's `async for` loop finishes normally.
6. **`for delta in _content_deltas(...): yield delta`** passes each piece of text on. `yield` pauses `stream()` until the caller asks for the next piece, so the text flows through as fast as the caller reads it and nothing is buffered.
7. **`except httpx2.HTTPError`** catches network problems that happen while the stream is being read, such as a dropped connection, a timeout between chunks, or the wrong content type (`SSEError`). A `ProviderError` raised inside the block isn't an `HTTPError`, so it passes through unchanged.

When the `async with` block exits, whether normally, through an error, or because the caller stopped early, the HTTP response is closed.

**`_content_deltas()`**: turns one event's JSON into zero or more strings.
- If the JSON doesn't parse, or contains `"error"`, it raises `ProviderError`.
- The list comprehension uses `.get(..., {})` and `.get("content")`, so chunks without `choices`, without a `delta` or with empty `content` give nothing instead of crashing. That's how the reasoning chunks and the final usage chunk are skipped.

Example: what Ollama sends, and what `stream()` yields:

| Event `data` | `_content_deltas` returns | Caller receives |
|---|---|---|
| `{"choices":[{"delta":{"content":"","reasoning":"Hmm"}}]}` | `[]` | nothing |
| `{"choices":[{"delta":{"content":"Hello"}}]}` | `["Hello"]` | `"Hello"` |
| `{"choices":[{"delta":{"content":" there"}}]}` | `[" there"]` | `" there"` |
| `{"choices":[],"usage":{...}}` | `[]` | nothing |
| `[DONE]` | (not parsed) | the loop ends |

## Step 4 — `app/providers/factory.py`: build from config

```python
from app.config import Settings
from app.providers.base import Embedder, LLMClient
from app.providers.ollama import OllamaEmbedder, OllamaLLMClient


def create_embedder(settings: Settings) -> Embedder:
    match settings.embedding_provider:
        case "ollama":
            return OllamaEmbedder(
                base_url=settings.ollama_base_url,
                model=settings.embedding_model,
                dim=settings.embedding_dim,
                document_prefix=settings.embedding_document_prefix,
                query_prefix=settings.embedding_query_prefix,
            )


def create_llm_client(settings: Settings) -> LLMClient:
    match settings.llm_provider:
        case "ollama":
            return OllamaLLMClient(
                base_url=settings.ollama_base_url,
                model=settings.llm_model,
                reasoning_effort=settings.llm_reasoning_effort,
                timeout=settings.llm_timeout_seconds,
            )
```

- **This is the only place that knows the concrete classes.** Everything else asks for an `Embedder` or an `LLMClient`.
- **There is no `case _:`.** The setting is a `Literal`, so the `match` covers every value and mypy knows it. When a value is added to the `Literal` but not here, mypy fails with `Missing return statement`. That's the reminder to add the case.
- **The embedder keeps its 60 s default timeout.** Embedding a batch is quick compared with generating an answer.

### How the code works

- **`match settings.embedding_provider:`** compares the setting with each `case`. `case "ollama":` matches the string `"ollama"`, and that branch builds and returns the object.
- **Settings in, constructor arguments out.** The factory is the only place where `.env` names meet class arguments:

  | Setting (`.env`) | Constructor argument |
  |---|---|
  | `OLLAMA_BASE_URL` | `base_url` (both classes) |
  | `EMBEDDING_MODEL` / `LLM_MODEL` | `model` |
  | `EMBEDDING_DIM` | `dim` |
  | `EMBEDDING_DOCUMENT_PREFIX` / `EMBEDDING_QUERY_PREFIX` | `document_prefix` / `query_prefix` |
  | `LLM_REASONING_EFFORT` | `reasoning_effort` |
  | `LLM_TIMEOUT_SECONDS` | `timeout` (LLM only) |

- **The return types are the Protocols** (`-> Embedder`, `-> LLMClient`), not the Ollama classes. A caller can't reach anything Ollama-specific, even by accident, so no Ollama detail leaks upstream.
- **The Ollama classes never import `Settings`.** They get plain values. That's why the tests in Step 6 can build them with any values they like.

How a caller will use it (F1.5 does this in the worker):

```python
embedder = create_embedder(get_settings())
try:
    vectors = await embedder.embed_documents(chunk_texts)
finally:
    await embedder.aclose()  # close the connection pool even if embedding failed
```

Adding a provider later, for example an OpenAI embedder, takes three edits:
1. `embedding_provider: Literal["ollama", "openai"]` in `config.py`
2. An `OpenAIEmbedder` class with the same methods, in `providers/openai.py`
3. A `case "openai": return OpenAIEmbedder(...)` here

Until step 3 is done, mypy fails with `Missing return statement`. The callers don't change at all.

## Step 5 — `tests/fakes.py`: the fake providers

```python
import hashlib
from collections.abc import AsyncIterator, Sequence

from app.providers.base import ChatMessage


class FakeEmbedder:
    """Same text, same vector, with no model. Records what it was asked to embed."""

    def __init__(self, dim: int = 8) -> None:
        self._dim = dim
        self.documents: list[str] = []
        self.queries: list[str] = []

    @property
    def dim(self) -> int:
        return self._dim

    async def embed_documents(self, texts: Sequence[str]) -> list[list[float]]:
        self.documents.extend(texts)
        return [self._vector(text) for text in texts]

    async def embed_query(self, text: str) -> list[float]:
        self.queries.append(text)
        return self._vector(text)

    async def aclose(self) -> None:
        pass

    def _vector(self, text: str) -> list[float]:
        digest = hashlib.sha256(text.encode()).digest()
        return [digest[i % len(digest)] / 255 for i in range(self._dim)]


class FakeLLMClient:
    """Streams a scripted reply. Records the messages of every call."""

    def __init__(self, reply: Sequence[str] = ("Hello", ", ", "world")) -> None:
        self._reply = list(reply)
        self.calls: list[list[ChatMessage]] = []

    async def stream(
        self,
        messages: Sequence[ChatMessage],
        *,
        temperature: float = 0.2,
        max_tokens: int | None = None,
    ) -> AsyncIterator[str]:
        self.calls.append(list(messages))
        for delta in self._reply:
            yield delta

    async def aclose(self) -> None:
        pass
```

- **Deterministic.** The same text always gets the same vector, so a test can assert on retrieval order without a model.
- **They record their calls.** Later tests can check *what* a service sent. For example, the ingestion tests can check that the chunks were embedded with their title prefix, and the chat tests that the prompt contained the numbered sources.
- **The file is not named `test_*.py`, so pytest doesn't collect it.** It's imported as `tests.fakes`; that works because `tests/__init__.py` exists.

## Common problems

| Symptom | Cause | Fix |
|---|---|---|
| Answer is empty, `finish_reason` is `length` | Thinking used up `max_tokens` | `LLM_REASONING_EFFORT=none` in `.env`, then recreate `api` |
| First answer takes minutes | Model loading, or a long prompt on a CPU | Normal on CPU. Raise `LLM_TIMEOUT_SECONDS` if you see `ReadTimeout` |
| `ProviderError: ... 404: model '...' not found` | Model in `.env` isn't pulled | `.\scripts\setup-ollama.ps1` |
| `ProviderError: ... ConnectError` in the container | Ollama not running, or `OLLAMA_BASE_URL` points at `localhost` | Start Ollama. Inside Docker the host is `host.docker.internal` |
| `returned N dimensions, but EMBEDDING_DIM is M` | `EMBEDDING_MODEL` changed without `EMBEDDING_DIM` | Set `EMBEDDING_DIM` to the model's size (the setup script prints it) |
| Prefix has no trailing space (Step 8) | Value not quoted in `.env` | `EMBEDDING_DOCUMENT_PREFIX="search_document: "` |
| `SSEError: Expected response with content type 'text/event-stream'` | `OLLAMA_BASE_URL` points at something that isn't Ollama, or at a proxy | Check `Invoke-RestMethod $OLLAMA_BASE_URL/api/version` |

| `ModuleNotFoundError: No module named 'tests'` | Running pytest from the repo root | Run from `docqa-backend`; keep `tests/__init__.py` |
