# S0.2.1 — Typed config and a health check

> **As a Dev, I want a FastAPI app with typed config and a health check, so that I have a base to build on.**

**Acceptance criteria:**
1. `app/main.py` with an `/api/v1` router
2. Config through **pydantic-settings**
3. `GET /api/v1/health` checks **Postgres**, **Redis** and **Ollama**, and returns the status of each one

**Size:** S (up to half a day). Depends on S0.1.1–S0.1.3. Ollama must be running on the host with the models pulled (S0.1.2).

**Out of scope, don't build it yet:**
- SQLAlchemy, sessions and Alembic are S0.2.2. The database check here uses plain `asyncpg`, which S0.2.2 installs anyway.
- A pgvector check. The `vector` extension is only enabled by the first migration in S0.2.2.
- The `Embedder` and `LLMClient` classes are S0.2.3. The Ollama check only lists the pulled models.
- CORS middleware and auth. The settings for them are added now, but nothing reads them yet.

## Step 2 — Typed config (`app/config.py`)

```python
from functools import lru_cache
from pathlib import Path
from typing import Annotated, Literal

from pydantic import SecretStr, field_validator
from pydantic_settings import BaseSettings, NoDecode


class Settings(BaseSettings):
    """Typed config. Each field reads the env var of the same name (case-insensitive)."""

    app_env: Literal["development", "production"] = "development"

    database_url: str
    redis_url: str = "redis://localhost:6379/0"

    ollama_base_url: str = "http://localhost:11434"
    llm_model: str = "qwen3:8b"
    embedding_model: str = "nomic-embed-text"
    embedding_dim: int = 768

    jwt_secret: SecretStr
    access_token_minutes: int = 30
    refresh_token_days: int = 7

    storage_dir: Path = Path("/data/storage")
    max_upload_mb: int = 50
    max_pages: int = 500

    # NoDecode: take the raw string instead of parsing it as JSON, then split it below
    cors_origins: Annotated[list[str], NoDecode] = ["http://localhost:5173"]

    @field_validator("cors_origins", mode="before")
    @classmethod
    def split_commas(cls, value: object) -> object:
        if isinstance(value, str):
            return [origin.strip() for origin in value.split(",") if origin.strip()]
        return value


@lru_cache
def get_settings() -> Settings:
    # Cached, so the environment is read once per process
    return Settings()  # type: ignore[call-arg]  # required fields come from the environment
```

**What it does:**
- Every backend variable in `.env.example` gets a field with a type. `MAX_PAGES=abc` or `APP_ENV=prod` now stops the app at startup with a clear error, instead of failing later somewhere deep in the code.
- `DATABASE_URL` and `JWT_SECRET` have no default, so they must be set. Everything else defaults to the values in `.env.example`.
- `jwt_secret` is a `SecretStr`. It prints as `**********` in logs and tracebacks. Read it with `settings.jwt_secret.get_secret_value()`.
- `CORS_ORIGINS` in `.env` is comma-separated. pydantic-settings would try to parse a `list` as JSON, so `NoDecode` turns that off and the validator splits on commas.
- No `env_file=".env"`. Docker Compose already passes `.env` to the containers, and the root `.env` uses Docker hostnames (`postgres`, `redis`) that don't work from the host anyway.
- The `# type: ignore[call-arg]` is needed because mypy can't see that the required fields come from the environment.

**Use it** through `get_settings()`, never by building `Settings()` yourself. In routes, take it as a dependency (`Depends(get_settings)`). Tests can then swap it with `app.dependency_overrides`.

## Step 4 — The health check (`app/api/health.py`)

```python
import asyncio
import time
from collections.abc import Awaitable, Callable
from typing import Annotated, Literal

import asyncpg
import httpx2
from fastapi import APIRouter, Depends, Response, status
from pydantic import BaseModel
from redis.asyncio import Redis

from app.config import Settings, get_settings

router = APIRouter(tags=["health"])

# A check that takes longer than this counts as down
CHECK_TIMEOUT_SECONDS = 3.0


class CheckResult(BaseModel):
    status: Literal["ok", "error"]
    latency_ms: int
    error: str | None = None


class HealthResponse(BaseModel):
    status: Literal["ok", "degraded"]
    checks: dict[str, CheckResult]


async def check_database(settings: Settings) -> None:
    # asyncpg wants a plain postgresql:// URL, without SQLAlchemy's "+asyncpg"
    dsn = settings.database_url.replace("postgresql+asyncpg://", "postgresql://", 1)
    conn = await asyncpg.connect(dsn)
    try:
        await conn.fetchval("SELECT 1")
    finally:
        await conn.close()


async def check_redis(settings: Settings) -> None:
    client = Redis.from_url(settings.redis_url)
    try:
        await client.ping()
    finally:
        await client.aclose()


def _with_tag(model: str) -> str:
    # Ollama lists "nomic-embed-text" as "nomic-embed-text:latest"
    return model if ":" in model else f"{model}:latest"


async def check_ollama(settings: Settings) -> None:
    async with httpx2.AsyncClient(base_url=settings.ollama_base_url) as client:
        response = await client.get("/api/tags")
        response.raise_for_status()
    pulled = {model["name"] for model in response.json()["models"]}
    missing = [
        name
        for name in (settings.llm_model, settings.embedding_model)
        if _with_tag(name) not in pulled
    ]
    if missing:
        raise RuntimeError(f"model not pulled: {', '.join(missing)}")


async def _run(check: Callable[[Settings], Awaitable[None]], settings: Settings) -> CheckResult:
    start = time.perf_counter()
    try:
        async with asyncio.timeout(CHECK_TIMEOUT_SECONDS):
            await check(settings)
    except Exception as exc:
        # Some exceptions (TimeoutError) have no message, so fall back to the type name
        error = str(exc) or type(exc).__name__
        return CheckResult(status="error", latency_ms=_elapsed_ms(start), error=error)
    return CheckResult(status="ok", latency_ms=_elapsed_ms(start))


def _elapsed_ms(start: float) -> int:
    return round((time.perf_counter() - start) * 1000)


@router.get("/health")
async def health(
    response: Response, settings: Annotated[Settings, Depends(get_settings)]
) -> HealthResponse:
    # Run the checks in parallel, so one slow dependency doesn't delay the others
    database, redis, ollama = await asyncio.gather(
        _run(check_database, settings),
        _run(check_redis, settings),
        _run(check_ollama, settings),
    )
    checks = {"database": database, "redis": redis, "ollama": ollama}
    healthy = all(check.status == "ok" for check in checks.values())
    if not healthy:
        response.status_code = status.HTTP_503_SERVICE_UNAVAILABLE
    return HealthResponse(status="ok" if healthy else "degraded", checks=checks)
```

**What it does:**
- Each `check_*` function raises if its dependency isn't usable, and returns nothing if it is. `_run` turns that into a `CheckResult` with the time it took and the error message.
- **Database:** opens a connection and runs `SELECT 1`. This proves the host, port, user, password and database name are all right.
- **Redis:** sends `PING`.
- **Ollama:** calls `GET /api/tags` and checks that both `LLM_MODEL` and `EMBEDDING_MODEL` are pulled. Ollama being up with a missing model is the most likely problem here, so it counts as an error.
- Every check has a 3-second limit. Without it, a dependency that never answers would make `/health` hang.
- All good: **200**, `"status": "ok"`. Anything down: **503**, `"status": "degraded"`, so scripts and load balancers can read the status code alone, and people can read the body to see what's wrong.

A healthy response looks like this:

```json
{
  "status": "ok",
  "checks": {
    "database": {"status": "ok", "latency_ms": 12, "error": null},
    "redis": {"status": "ok", "latency_ms": 3, "error": null},
    "ollama": {"status": "ok", "latency_ms": 41, "error": null}
  }
}
```

```python
import pytest
from pydantic import ValidationError

from app.config import Settings


def test_cors_origins_splits_commas(monkeypatch: pytest.MonkeyPatch) -> None:
    monkeypatch.setenv("CORS_ORIGINS", "http://localhost:5173, http://example.com")

    settings = Settings()  # type: ignore[call-arg]

    assert settings.cors_origins == ["http://localhost:5173", "http://example.com"]


def test_wrong_type_is_rejected(monkeypatch: pytest.MonkeyPatch) -> None:
    monkeypatch.setenv("EMBEDDING_DIM", "not-a-number")

    with pytest.raises(ValidationError, match="embedding_dim"):
        Settings()  # type: ignore[call-arg]


def test_missing_required_value_is_rejected(monkeypatch: pytest.MonkeyPatch) -> None:
    monkeypatch.delenv("DATABASE_URL")

    with pytest.raises(ValidationError, match="database_url"):
        Settings()  # type: ignore[call-arg]


def test_jwt_secret_is_hidden_when_printed() -> None:
    settings = Settings()  # type: ignore[call-arg]

    assert "test-secret" not in repr(settings)
```

These build `Settings()` directly on purpose, to test parsing. `monkeypatch` puts the environment back after each test.

**`tests/test_health.py`** (replace the old smoke test):

```python
import asyncio

import pytest
from fastapi.testclient import TestClient

from app.api import health
from app.config import Settings
from app.main import app

client = TestClient(app)


async def ok(settings: Settings) -> None:
    return None


async def down(settings: Settings) -> None:
    raise ConnectionError("connection refused")


@pytest.fixture(autouse=True)
def all_ok(monkeypatch: pytest.MonkeyPatch) -> None:
    # Swap out the real checks, so the tests don't need Postgres, Redis or Ollama
    monkeypatch.setattr(health, "check_database", ok)
    monkeypatch.setattr(health, "check_redis", ok)
    monkeypatch.setattr(health, "check_ollama", ok)


def test_health_ok_when_all_checks_pass() -> None:
    response = client.get("/api/v1/health")

    assert response.status_code == 200
    body = response.json()
    assert body["status"] == "ok"
    assert {name: check["status"] for name, check in body["checks"].items()} == {
        "database": "ok",
        "redis": "ok",
        "ollama": "ok",
    }


def test_health_503_when_one_check_fails(monkeypatch: pytest.MonkeyPatch) -> None:
    monkeypatch.setattr(health, "check_redis", down)

    response = client.get("/api/v1/health")

    assert response.status_code == 503
    body = response.json()
    assert body["status"] == "degraded"
    assert body["checks"]["redis"]["status"] == "error"
    assert body["checks"]["redis"]["error"] == "connection refused"
    assert body["checks"]["database"]["status"] == "ok"


def test_slow_check_times_out(monkeypatch: pytest.MonkeyPatch) -> None:
    async def hangs(settings: Settings) -> None:
        await asyncio.sleep(10)

    monkeypatch.setattr(health, "CHECK_TIMEOUT_SECONDS", 0.05)
    monkeypatch.setattr(health, "check_ollama", hangs)

    response = client.get("/api/v1/health")

    assert response.status_code == 503
    assert response.json()["checks"]["ollama"]["error"] == "TimeoutError"
```

The fakes work because `health()` looks up `check_database` and the others by name each time it runs, so `monkeypatch.setattr` on the module replaces them.

## Common problems

| Symptom | Cause | Fix |
|---|---|---|
| API exits with `Field required` for `database_url` | No `.env`, or the variable is missing | `Copy-Item .env.example .env`, then `docker compose up -d` |
| `ModuleNotFoundError: pydantic_settings` in the container | Image built before the requirements change | `docker compose up -d --build api worker` |
| pytest: `Field required` at import | `tests/conftest.py` missing or not in `tests/` | Create it as in Step 6 |
| mypy: `asyncpg ... missing library stubs` | `asyncpg-stubs` not installed | `pip install -r requirements-dev.txt`, and add it to the pre-commit hook (Step 7) |
| `CORS_ORIGINS`: `error parsing value` | The `NoDecode` annotation is missing | Use `Annotated[list[str], NoDecode]` as in Step 2 |
| `ollama` error: `All connection attempts failed` | Ollama not running, or `OLLAMA_BASE_URL` wrong | Start Ollama; inside Docker the URL is `http://host.docker.internal:11434` |
| `ollama` error: `model not pulled` | Model in `.env` not pulled yet | `.\scripts\setup-ollama.ps1` |
| `database` error: `password authentication failed` | Postgres volume was created with other credentials | Match `.env` to the first-run values, or reset with `docker compose down -v` (deletes the data) |
